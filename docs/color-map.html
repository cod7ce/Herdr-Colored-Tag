实现边界与核对依据

侧栏 token：fg / bold / dim 是文字样式；没有 token 的 bg。规则判断当前 token 的显示值，不能跨 token 查询标签或 Space ID。来源：src/config/sidebar/rules.rs、src/ui/sidebar/tokens.rs。

Agents 数据：agent 的显示名、所属 Space 名和 pane 元数据分别解析；不自动继承 workspace 的自定义元数据。来源：src/client/shell/agent_sidebar.rs、src/api/schema/agents.rs。

原生 worktree：子项有自己的标题匹配值，部分自动标题由分支生成；不能仅用父 Space 的规则覆盖子项。来源：src/client/shell/sidebar.rs。

全局主题：[theme.custom] 可以覆盖共享配色字段，例如 accent、sidebar_bg、active_row_bg、panel_bg、overlay0。同一字段被多个区域复用，不等于每处可独立指定颜色。来源：src/config/theme.rs 及对应 UI 渲染代码。

配置生效：需要通过 Herdr 配置重载应用并检查结果；本页完全离线，只展示位置。当前插件管理的颜色块带完整性校验，扩展应由插件维护，避免直接修改其生成的配置段。
